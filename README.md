# Notes App

Консольное приложение для ведения заметок на Python. Заметки сохраняются в файл `notes.json`.

## Возможности

- добавление заметки;
- просмотр списка заметок;
- удаление заметки по номеру;
- поиск заметок по тексту (без учёта регистра).

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | Код приложения |
| `requirements.txt` | Инструменты разработки (flake8, pytest) |
| `README.md` | Описание проекта |

## Запуск

```bash
git clone https://github.com/space32-web/notes-app.git
cd notes-app
python main.py
```

Требуется Python 3.10 или новее.

## Меню

| Клавиша | Действие |
|---|---|
| 1 | Добавить заметку |
| 2 | Показать список |
| 3 | Удалить заметку |
| 4 | Найти заметки |
| 0 | Выход |
